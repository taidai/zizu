# ZiZu 0.4.86 节点数据主干易用性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让实施工程师通过公开界面完成节点维护、多组点位导入、L0 实时诊断和点位加工模板创建/应用，并发布 0.4.86 到 1 号机。

**Architecture:** 保持真实节点树 → L0 → L1 → L2 唯一主干。配置入口写入统一配置修订并经栅栏重载实时黑板；所有实时页面只读取 committed 帧。点位加工继续复用现有 validate/import/plan/apply 原子发布缝。

**Tech Stack:** FastAPI、PostgreSQL/TimescaleDB、React/TypeScript、NanoMQ、Neuron、pytest、Node test、Docker Buildx。

**Spec:** `docs/superpowers/specs/2026-08-29-node-l0-template-usability-design.md`

## Global Constraints

- 发布版本固定为 `0.4.86`，不得使用 rc 后缀。
- 不新增依赖、微服务、Redis、Kafka、设备实例、独立设备模板或第二套规则引擎。
- 1 号机保留 `network_mode: host` 与 `/dev/mqueue` tmpfs；不启用 Caddy/TLS，不做设备写或自动策略验证。
- 所有行为变更先写失败测试并观察 RED，再写最小实现。
- 保留工作树中无关的未跟踪部署说明，不覆盖用户改动。
