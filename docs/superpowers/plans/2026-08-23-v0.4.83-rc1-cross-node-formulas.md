# v0.4.83-rc.1 跨节点公式与全站 DAG 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 L0 → L1 点位加工 → L2 数据主干上交付安全强类型跨节点公式、冻结选择器、全站 DAG 门禁和可视化/文本双模式编辑，并发布可独立验收的 `v0.4.83-rc.1`。

**Architecture:** 跨节点加工只读取已提交的 L2，安装在输出所属物理节点；配置导入时把白名单 DSL 编译为规范 AST，计划时把选择器展开并冻结为明确实体实例，应用前对全站依赖图执行循环与八层深度检查。运行期按 1～3600 秒整数周期读取同一计算时点的 L2 latest，通过现有 L2 持久化、来源证据和 outbox 事务链提交结果；可视化编辑器与文本编辑器只生成同一种 DSL/AST，不形成第二套执行器。

**Tech Stack:** Python 3.13、FastAPI、Pydantic、PostgreSQL/TimescaleDB、Pint、React 18、TypeScript、Vite、Docker Buildx/GHCR。

**Spec:** `docs/superpowers/specs/2026-08-23-point-processing-en9-cross-node-design.md`

## Global Constraints

- 版本固定为 `0.4.83`，首个候选为 `v0.4.83-rc.1`；已发布的 `v0.4.82-rc.2` 永不移动或复用。
- Schema 从完整 041 原子升级为 042；新应用遇到旧、混合或未登记结构时拒绝启动。
- 本节点加工可读取本节点 L0；跨节点加工只能读取 L2，并安装在输出实体所属节点。
- 选择器只允许“目标节点子树 + 节点类型 + 实体定义”，preview 展开明确 UUID 清单，apply 复核站点版本与清单摘要后冻结；新增设备不自动加入现行公式。
- DSL 只允许算术、比较、布尔逻辑、条件、`abs/min/max/clamp/convert/sum/avg/weighted_sum/min_of/max_of/count`；禁止 Python/JavaScript、属性访问、动态导入、网络、文件、数据库查询与系统命令。
- 全站依赖图拒绝自环、跨站引用、循环和超过 8 层的链；稳定错误码分别为 `POINT_PROCESSING_DAG_CYCLE`、`POINT_PROCESSING_DAG_DEPTH_EXCEEDED`、`POINT_PROCESSING_SELECTOR_STALE`、`POINT_PROCESSING_FORMULA_INVALID`。
- 必需输入 BAD/STALE 使输出无值且质量失效；可选输入只有显式默认值才可继续，结果为 UNCERTAIN。
- 公式周期必须是 1～3600 秒整数；本版本不实现时间窗口、检查点、历史重算和自动策略验证，它们属于 `v0.4.84-rc.1`。
- 不建立 L1 时序表，不增加依赖，不执行设备写命令，不修改 Neuron，不启动 Caddy，不申请 TLS。
- 每项生产行为先执行 RED，再写最小实现并执行 GREEN；每个任务形成独立提交。

```sql
CREATE TABLE t_point_processing_expressions (
  output_id UUID PRIMARY KEY REFERENCES t_point_processing_outputs(id),
  dsl_text TEXT NOT NULL CHECK (btrim(dsl_text) <> ''),
  canonical_ast JSONB NOT NULL,
  ast_digest CHAR(64) NOT NULL,
  result_data_type TEXT NOT NULL CHECK (result_data_type IN ('FLOAT','INT','BOOL')),
  result_unit TEXT,
  schedule_seconds INTEGER NOT NULL CHECK (schedule_seconds BETWEEN 1 AND 3600),
  control_eligible BOOLEAN NOT NULL DEFAULT FALSE
);

CREATE TABLE t_point_processing_selectors (
  input_id UUID PRIMARY KEY REFERENCES t_point_processing_inputs(id),
  scope TEXT NOT NULL CHECK (scope = 'descendants'),
  node_type TEXT NOT NULL CHECK (btrim(node_type) <> ''),
  entity_definition_id TEXT NOT NULL CHECK (btrim(entity_definition_id) <> ''),
  cardinality TEXT NOT NULL CHECK (cardinality IN ('one','many')),
  default_value JSONB
);

CREATE TABLE t_point_processing_selector_members (
  installed_processing_id UUID NOT NULL REFERENCES t_installed_point_processings(id),
  input_id UUID NOT NULL REFERENCES t_point_processing_inputs(id),
  ordinal INTEGER NOT NULL CHECK (ordinal >= 0),
  entity_instance_id UUID NOT NULL REFERENCES t_entity_instances(id),
  PRIMARY KEY(installed_processing_id, input_id, ordinal),
  UNIQUE(installed_processing_id, input_id, entity_instance_id)
);
```

- [ ] **Step 3: 实现规范 AST 编译器**

使用 Python `ast.parse(..., mode='eval')` 只做语法解析，再逐节点转换成自有 JSON AST；只接受 `Constant/Name/BinOp/UnaryOp/BoolOp/Compare/IfExp/Call` 白名单，拒绝 `Attribute/Subscript/Lambda/Comprehension`。通过 Pint 在编译时验证加减比较单位一致、乘除单位可推导、`convert(value, "kW")` 目标兼容；所有常量必须为有限数字或布尔值。

```python
@dataclass(frozen=True)
class CompiledFormula:
    text: str
    ast: Mapping[str, Any]
    digest: str
    result_kind: ValueKind
    result_unit: str | None

@dataclass(frozen=True)
class FormulaTransform:
    sources: Mapping[str, tuple[InputReference, ...]]
    source_contracts: Mapping[str, FormulaSource]
    compiled: CompiledFormula
    schedule_seconds: int
    control_eligible: bool
```

- [ ] **Step 4: 实现纯求值与 fail-closed 质量语义**

求值器只遍历规范 AST。必需来源缺失/BAD/STALE 返回无值同质量；可选来源缺失且声明默认值时继续并把结果降为 UNCERTAIN；除零、溢出、非有限结果分别返回 `DIVIDE_BY_ZERO`、`OVERFLOW`、`INVALID_NUMBER`。来源 UUID、digest、时间戳和顺序键覆盖实际参与计算的所有 L2 观测。
