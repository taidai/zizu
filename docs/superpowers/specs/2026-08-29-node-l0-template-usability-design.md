# 节点、L0 与点位加工模板易用性收口设计

## 1. 目标

本轮只修好节点数据主干已经存在但无法顺畅使用的四个入口：节点树维护、Neuron 点位导入、L0 实时与历史、点位加工模板维护。不得新增设备实例、独立设备模板、第二条实时链或绕过 L2 的上层输入。

用户闭环固定为：

```text
维护真实节点 → 批量导入 Neuron 点位 → 看见 L0 实时/历史
             → 从当前设备创建或选择点位加工模板
             → 检查并原子应用 → 看见 L2 实时/历史/来源
```

## 2. 决策

### 2.1 节点树

- 支持新建根节点和子节点、修改名称/类型/排序/启用状态/上级节点。
- 上级节点变化时，服务端在一个事务内检查循环并重算整个子树层级。
- 用户删除节点时，该节点及其子树立即退出活动节点树、采集目录和运行配置，界面只需普通确认。
- “删除”是运行硬切，不删除不可变配置修订、L1/L2 来源证据、历史告警和统一审计；这些记录继续使用原资源标识追溯。最新“总纲优先”决定覆盖此前无痕物理删除选择。
- 节点变更成功后推进配置修订，并通过配置栅栏重载实时黑板；失败时整个事务回滚。

### 2.2 Neuron 点位导入

- 用户先选择一个 Neuron 南向节点，再勾选一个或多个采集组。
- 预览返回每个来源点位的 `create`、`update`、`unchanged` 或 `conflict` 结果，以及不可变预览摘要。
- 正式导入必须携带同一摘要；Neuron 内容或站点配置已变化时拒绝陈旧预览。
- 点位身份使用 `node_id + source_type + source_path`。重复导入更新原记录并保留 tag UUID 与历史，不按显示名称制造副本。
- 导入文件没有出现的旧点位不自动删除；数据类型等会破坏活动 L1 合同的变化标为冲突并阻止整批提交。
- 提交成功后立即推进配置修订、刷新采集目录并重载黑板，不要求重启服务。

### 2.3 L0 实时语义

- 所有启用的 `PHYSICAL` 点位都是活动 L0 诊断输入；是否被 L1 使用不影响它能否显示实时值。
- 只有活动 L1 的必需 L0 输入属于 WARMING 必需集合，未加工点位不得阻塞数据帧主干。
- 值相同但来源顺序更新的样本仍是新观测：在下一统一节拍保存其 L0 事实并推进数据时间。没有新观测则不制造新帧。
- 迟到或倒序样本丢弃；连续三拍没有新样本转为 STALE。
- 页面只展示 committed L0：首次 REST 快照，之后统一 committed-frame WebSocket 增量；历史仍从共享 L0 时序表查询。

### 2.4 点位加工模板

“点位加工”页提供清晰的 `模板库` 与 `本节点应用` 两个任务入口，不再把管理员模板编辑器藏在安装流程中。

- 模板库：浏览、搜索、导入、导出、复制修订、从当前设备创建模板；操作员只读，实施工程师使用，管理员维护共享模板。
- 从当前设备创建时直接列出本节点 L0，用户勾选输入、定义 L2 输出，并选择直接映射、单位换算、状态映射、公式或统计加工。
- 本节点应用：选择推荐模板、自动匹配确定输入、人工处理缺失/歧义、查看 L2 输出与阻断。
- 普通用户只有一个主动作“检查并应用”。后台仍依次执行强类型校验、在线试算、计划摘要复核和原子发布；这不是直接覆盖。
- 模板发布产生不可变新修订；实例绑定调整只影响当前节点，其他已投运节点不自动升级。
- 任一公式、类型、单位、DAG 或输入校验失败时拒绝应用，旧活动修订继续运行。

## 3. 接口

- `POST /api/v1/tags/import-neuron/preview`：请求包含 `node_id`、`neuron_node`、`neuron_groups[]`；返回预览摘要、基线配置修订、逐点动作和汇总。
- `POST /api/v1/tags/import-neuron`：同一请求再携带 `preview_digest`；整批原子提交。旧单分组请求硬切删除，不保留运行期 fallback。
- 现有节点 POST/PUT/DELETE 路径保留；PUT 开放 `parent_id`，DELETE 执行子树运行退役并返回影响计数。
- 现有模板 validate/import、plan/apply 接口继续作为唯一发布缝；前端组合成“检查并应用”，不新增旁路保存接口。

## 4. 数据结构

Schema 050 最小增加：

- 节点运行退役状态及退役时间；活动节点查询统一排除退役节点。
- Neuron PHYSICAL 点位的来源身份唯一索引。
- 导入预览所需的配置修订/内容摘要不持久保存为新业务表，由请求时计算并在应用时重算。

不建立每节点表、L1 时序表、模板草稿服务或额外消息中间件。

## 5. 验收

1. 实施工程师可在界面完成根/子节点新建、编辑、移动、启停和删除；非法循环与并发修改被原子拒绝。
2. 一次选择多个 Neuron 分组，预览后导入；再次导入只更新原点位且 UUID 不变。
3. PCS 所有启用 PHYSICAL 点位无需先绑定 L1 即可显示 committed 实时值、质量、时间与历史。
4. 相同值的新样本刷新时间；没有新样本不拍照；三拍无样本转 STALE；迟到数据不回拨 latest。
5. 管理员可从当前 PCS L0 创建共享模板，实施工程师可用一个“检查并应用”动作在当前节点生成稳定 L2。
6. 错误模板不生效，旧修订继续运行；其他使用同模板的节点不被自动升级。
7. 1 号机固定摘要部署后完成以上界面与接口验收；不做设备写、自动策略、Caddy 或 TLS。
