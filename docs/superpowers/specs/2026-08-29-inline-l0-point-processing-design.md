# 原始点位内联加工设计

**状态：** 已确认（Accepted）  
**日期：** 2026-08-29  
**权威依据：** `2026-08-27-zizu-platform-core-architecture-design.md`

## 1. 目标

实施工程师在所选节点的“原始点位”页面直接选择一个或多个 L0，点击“加工为实体”，配置加工方法、
检查结果并发布 L2。普通用户不再面对独立的“点位加工”页面、模板修订、计划摘要或 L1 术语。

内部主干不变：L0 仍是不可修改的协议事实；L1 仍是版本化、强类型、可审计且原子发布的执行层；
L2 仍是上层唯一接口。界面合并不能变成覆盖 L0、绕过 L1 或直接创建无来源 L2。

### 1.1 中立产品基线（2026-08-29 确认）

- L0/L1/L2 是内部数据架构，不是要求实施工程师学会的三个产品模块。
- 普通用户在节点下只面对“原始数据”和“标准实体”两个任务页。
- L1 作为每个标准实体的“数据来源与计算”内联编辑，隐藏模板修订、DAG、计划 ID 和摘要等技术负担。
- 共享模板是一台真实设备配置成功后的管理员复用工具，不是创建标准实体的前置条件。
- 产品验收必须以真实纵向闭环为证据，不再以页面存在、接口存在或历史“已确认”作为完成证据。

## 2. 用户路径

```text
选择节点
  → 查看原始点位实时/历史
  → 勾选一个或多个原始点位
  → 加工为实体
  → 直接使用 / 乘除换算 / 状态对应 / 高级公式
  → 填写实体名称、业务键、类型、单位和新鲜度
  → 检查结果
  → 发布
  → 在“标准实体”查看实时、历史和来源
```

节点详情只保留“原始数据”和“标准实体”两个任务页。L1 只作为标准实体的“数据来源与计算”出现，完整技术详情只对管理员开放。

## 3. 原始事实与加工边界

- 加工入口位于 L0 页面，但加工永不修改 L0 的值、类型、单位、质量、时间或来源。
- 同节点加工可以读取本节点 L0；跨节点公式只能读取已提交 L2。
- 发布前校验类型、单位、输入唯一性、公式、DAG 和活动配置修订；任一失败整次不生效。
- 发布后仍由现有实时黑板、不可变帧和事务 A/B 执行；数据库提交前不推送、不告警、不控制。

## 4. 节点私有加工定义

普通工程师创建的是“节点私有加工定义”，不是共享模板。存储层复用现有不可变 L1 修订表，并增加：

- `reuse_scope = node | shared`；
- `owner_node_id`：`node` 时必填，`shared` 时为空；
- 节点私有定义只允许安装到所属节点，不出现在共享模板库；
- 预览可以保存不可变草稿和计划证据，但不切换运行态；
- 发布继续复用现有幂等 apply、配置栅栏和原子切换。

管理员可将当前节点私有定义显式“保存为共享模板”。该动作创建新的共享资产与修订，不改变当前节点
正在运行的修订，也不自动升级其他节点。

## 5. 界面规则

- L0 实时表增加复选框；切换节点时清空选择，翻页和筛选不丢失已选 ID。
- 未选择点位时“加工为实体”不可用；选择后在当前页面展开加工抽屉。
- 默认只展示直接使用、乘除换算和状态对应；公式放在“高级加工”。
- 普通首屏不显示模板 ID、摘要、修订 UUID、计划 ID、L0/L1/L2 术语和内部错误码。
- 检查结果必须展示将生成/更新/停止的实体、当前试算值、单位、质量及中文阻断原因。
- 发布成功后刷新实体数据，并提供“查看实体”入口。

## 6. 接口

- `POST /nodes/{node_id}/point-processing-drafts/plan`：接收节点私有加工内容和确定的 L0/L2 输入选择，
  校验并生成现有 `PointProcessingPlan`；不切换运行态。
- `POST /point-processing-plans/{plan_id}/apply`：继续使用现有摘要、幂等键和配置栅栏原子发布。
- `POST /nodes/{node_id}/point-processing-templates/promote`：管理员把当前节点私有修订复制为共享模板。
- 现有共享模板导入、验证、导出和安装接口保留给管理员及批量交付；普通节点流程不依赖它们。

## 7. 验收

1. 工程师不进入模板库即可把一个 PCS L0 直接加工为 L2，并看到实时、历史和来源。
2. 多选两个 L0 可创建强类型公式输出；类型、单位或循环错误会阻止发布。
3. 加工前后 L0 值和来源证据完全不变。
4. 节点私有定义不能安装到其他节点，也不出现在共享模板列表。
5. 管理员保存为共享模板后，新模板可在同类节点复用，原节点运行修订不变。
6. 独立“点位加工”页及普通用户模板前置步骤被删除；上层仍只消费 committed L2。

## 8. 不做

- 不在 L0 表直接修改原始事实；
- 不创建第二套加工引擎、表达式引擎或时序表；
- 不允许任意脚本、运行期模糊匹配或跨节点读取 L0；
- 不把节点私有定义自动提升为共享模板；
- 不恢复设备模板、解决方案或独立实体管理入口。
