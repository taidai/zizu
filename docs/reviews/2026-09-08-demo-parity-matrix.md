# ZiZu 本机 Demo → 正式产品对照矩阵

日期：2026-09-08

依据：`docs/superpowers/specs/2026-09-08-demo-final-product-parity-design.md`

目标版本：v1.0.5

状态：`INCOMPLETE` —— Demo 金标准已冻结；Task 9g 的 production-preview route fixture 因测试契约与生产服务方式不兼容而阻断，尚未关闭正式产品逐项验收

## 1. 这份矩阵约束什么

本机 Demo 决定正式产品的页面结构、视觉层级、信息密度、控件位置和主要操作路径；正式 v1.0.4 运行内核决定认证、权限、真实数据、配置发布、告警、JDM、控制安全门和回读语义。对照时只允许真实数值不同，不允许缺少页面区块、操作无入口、按钮遮挡，或用演示值掩盖未配置、过期、断线和失败。

金标准截图位于忽略目录 `.release-artifacts/v1.0.5/demo-golden/`。它们是本机 Demo 的界面证据，不是正式 API、现场设备或 v1.0.5 功能通过证明。

| --- | --- |

| 弹窗/抽屉 | 指标详情显示名称、值、单位、质量、数据时间、来源链和历史；工程角色另有固定槽位绑定弹窗。高级帧、配置修订和来源证据放详情，不挤占首页。 |

| 空态/异常 | 不用 `0` 或“正常”代替缺失。未配置、歧义、非 GOOD、过期、断线和请求失败分别可见；无可信方向依据时保留拓扑但不画方向；前端不得自行求和制造站点总功率。 |
| 明确排除 | 固定 89.2/68.2/22.0/40.4/26.8 数值、示例设备、演示采样、演示策略、“仅仿真”、合成历史、前端场景切换和内存槽位。 |

## 5. Demo-only 禁入清单

正式源码依赖图、构建产物和页面不得包含或执行以下 Demo 行为：

- `frontend/demo-tablet` 的任何运行时 import；
- “前端 DEMO”“本机演示”“交互原型”“演示状态”“体验身份”“重置演示”等横幅或控件；
- 角色切换、场景切换、故障注入、模拟设备恢复、模拟通知、模拟回读、浏览器内存发布；
- 固定节点、固定 L0/L2 数值、固定历史、固定告警和固定策略运行状态；
- 用 `0`、GOOD、正常、成功或静态方向替代未配置、歧义、STALE/BAD、断线、超时和结果未知；
