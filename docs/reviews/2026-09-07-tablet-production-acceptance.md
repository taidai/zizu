## JDM 兼容与限制

- 新通用表使用真实 GoRules `collect` 与 `intents`，每条控制意图显式提供 `action_id` 和 `target`；
- 一个求值结果重复同一 action 或同一实体时，simulation 和 evaluate 共用安全门：整体失败关闭，不产生控制意图；evaluate 只保留既有 FAILED 审计；
- 静态 INT／FLOAT 目标按真实 GoRules 的有限数值语义校验，不接受动态表达式、非有限值或非整数 INT；
- 完整 graph 不自动改写。历史已存的旧 `&&` 2充2放条件图不会自动迁移，必须显式修改为 GoRules 原生区间，重新保存、试算和发布；
- API 受理、JDM 命中、意图创建或页面刷新都不是设备成功；只有新 committed L2 回读匹配才算成功。
