# 主显示尺寸：10.1 寸横屏平板

主验收视口为1280×800 CSS像素，兼顾1024×768；桌面大屏是延展效果，不再作为首页验收样板。10.1寸本身不能确定分辨率，实际设备还需结合系统缩放及浏览器可用视口检查。

运行总览保留四张指标卡、左侧光伏/电网与右侧储能/充电/负荷；能流节点改成三行网格，不用固定百分比高度挤压质量、原因和来源文字。压缩卡片空白而非删掉数据状态，底部能流说明不被固定导航遮挡。关键按钮至少44 CSS像素。
