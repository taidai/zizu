# ZiZu 当前开发目标

ZiZu 的目标是让实施工程师不改源码、不写 SQL，仅通过配置即可交付单站光储充 EMS。唯一产品主干是：**真实节点树 → L0 原始点位 → L1 点位加工 → L2 全局实体 → 告警 / JDM / 控制 / 固定 EMS 工作台**。当前不扩展插件、通用页面设计器、新规则引擎、多租户或新基础设施；先把已有功能磨成一条普通实施人员能独立走通的闭环：维护节点，导入并查看原始点位实时/历史数据，在全局实体中选择来源、定义直接映射或强类型公式、试算并发布，再查看实体实时/历史/来源证据，最后用实体完成告警触发与恢复。每轮开发必须先写清要改变的用户结果，再以自动测试、生产构建和实际页面操作验收；代码存在、接口返回成功或页面出现按钮都不算交付。缺少现场或人工操作证据时只能标记“未完成”，不得宣称通过。

## 当前顺序

1. 先保证节点、L0、点位加工和 L2 的配置与查看真正可用。
2. 再把现有告警收成“选择实体 → 定义条件 → 发布 → 触发 → 恢复”的最小闭环。
3. 随后依次补齐 JDM 提交后消费、控制来源帧复核和 EMS 工作台提交帧读取。
