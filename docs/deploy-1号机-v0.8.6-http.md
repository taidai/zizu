## 变更

- L1 点位加工输出可声明受约束的 `control` 配置。
- 只有“同节点、已启用、Neuron 来源、RW、数值型、单 L0 直接使用”的加工结果可以成为可控 L2；公式、多点组合、只读点位均不能绕过检查。
- 发布时服务端再次核对唯一 L0 来源，并原子写入 L2 的 `RW` 方向、控制策略和唯一 `t_l2_control_bindings` 绑定。
- 控制策略包含最小值、最大值、容差、冷却时间、回读超时与高风险标记；策略占用或控制命令在途时禁止改绑。
- 界面仅对符合条件的直接加工显示“允许调度控制”，并提供安全参数；草稿无效时仍可点击“检查结果”查看具体原因。

## 尚未完成的真实验收

现场只有 4 个 L2，除本次可控 PCS 实体外均为 E2E 只读实体，没有真实 SOC 点位或实体。调度策略必须至少有一个独立输入和一个输出，并禁止同一实体同时充当输入与输出；两充两放策略也明确要求 SOC 输入。因此本次没有构造假 SOC，也没有执行计划中的 `156.8 → 156.7 → 156.8` 真实写入。要完成闭环，下一步只需把真实 BMS SOC 沿 L0、L1 发布为只读 L2，再在小功率窗口执行一次写入和 L2 回读确认。
