# ADR-0003：生产默认认证与不可变发布锁定

## Status

Accepted — 2026-08-12

## Context

当前用户表和 JWT 依赖尚未形成应用级安全边界，线上业务 API 与 WebSocket 可匿名访问。部署依赖 `latest`、预构建 ARM 镜像和宿主机代码覆盖，版本号无法证明实际运行内容。

## Decision

首版角色为 admin、engineer 和 operator，权限由服务端执行；高风险控制叠加命令级授权和可选二次确认。

生产模式默认认证所有业务 REST API 与 WebSocket，仅最小存活探针匿名。开发匿名必须显式开启并展示不安全状态。

平台以固定版本多架构镜像和 digest 发布，解决方案包独立语义版本。每次部署锁定平台版本、镜像 digest、数据库 Schema、解决方案包版本和站点配置版本，并只使用可验证的不可变制品升级或回滚。

## Consequences

- 需要实现登录、会话、RBAC、WebSocket 认证和端点权限矩阵。
- 现有匿名客户端和部署脚本需要迁移。
- 构建与发布链增加多架构构建、摘要校验和发布记录，但交付可重现且安全默认成立。
