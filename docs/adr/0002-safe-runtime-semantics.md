# ADR-0002：实体实例、告警状态机与统一控制命令

## Status

Accepted — 2026-08-12

## Context

当前全局实体无法安全表达多台同类设备，多候选绑定会按优先级和创建时间静默选源。告警处理按采样累加且允许人工恢复；设备写入存在多条旁路，写接口成功没有回读证据。

## Decision

实体定义表达标准语义，实体实例表达站点内实际运行对象。规则、工作台、告警和控制引用稳定的实体实例 ID。必需绑定在安装或升级阶段确定；零候选和多候选阻止交付就绪。

告警使用现场条件驱动的统一状态机，支持持续时间、迟滞、恢复条件和通知节流。确认仅表示操作员知悉，恢复只能由现场恢复条件产生。

所有人工和自动设备写入创建统一控制命令，执行权限、限值、联锁、幂等、持久冷却、审计和写后回读。只有回读达到声明的期望值、容差和超时要求才算成功。

## Consequences

- 需要迁移现有实体、绑定和告警数据，并为旧写入 API 提供有限兼容窗口。
- 运行时不再通过优先级猜测数据源，交付前必须解决配置缺口。
- 人工不能伪造故障恢复；运行记录更可信。
- 控制延迟和持久化成本增加，但命令结果可证明、可审计、可恢复。
