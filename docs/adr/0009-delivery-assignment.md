# ADR-0009：以交付分配向实施工程师授权固定解决方案包

## Status

Rejected — 2026-08-15

## Context

`solution.package.read` 曾只允许平台管理员，导致实施工程师看不到已经过完整校验的包和参数契约，
无法从产品界面开始交付。曾考虑引入独立的交付分配记录解决可见性问题。

产品目的地明确首版不建设工单、项目管理或审批系统，因此不能把此授权对象称为“工单”。

## Rejection

不引入交付分配模块。ZiZu 当前是**单站实例**，并非多租户包市场；已验证包的公开表示不含 Secret、
现场参数、物理地址或客户信息。让 engineer 只读该公开包目录，能以更小的系统复杂度闭合 UI
交付入口。

- admin 仍独占包导入、替换和生命周期管理；
- engineer 只读 `PackageImport.public_dict()`，并继续以既有公开计划、安装、验收主缝完成交付；
- 若未来引入多站、多客户隔离或非公开包资产，必须新建 ADR 重新评估分配记录，而不能依赖当前
  单站假设。

## Consequences

- 实施工程师现在可直接在产品界面选择已验证包，不需要数据库 UUID、源码或额外授权对象。
- 首版仍不引入通用工单系统；未来若需要排程、审批或多站项目管理，必须另立 ADR。
