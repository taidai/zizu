# ADR-0013：节点数据主干取代解决方案交付

ZiZu 将产品主线收敛为“节点 → L0 原始点位 → L1 点位加工 → L2 全局实体 → 告警/JDM/控制/固定 EMS 工作台”，并硬切删除解决方案包、解决方案安装、设备实例中间层和统一验收中心。L2 直接属于节点，L1 通过单个规范 JSON 模板完成复用；运行配置发布仍保留内部配置修订号、原子事务、审计、幂等和来源证据。我们接受失去跨资产打包、统一安装与统一报告的代价，以换取实施工程师只需理解节点树和数据主干、平台只有一条配置路径、代码不再围绕未被现场需要的交付抽象扩张。

本决策完全取代 ADR-0001、ADR-0006 和 ADR-0010；取代 ADR-0005 的设备实例、实例槽位和解决方案绑定部分，但保留稳定 L2 身份、确定绑定和禁止运行时猜测来源的不变量；取代 ADR-0012 的解决方案包资产与独立业务指标交付边界，但保留统计结果属于 L2、时间能力契约和自动控制 fail-closed 的安全语义。迁移采用单次 Schema 硬切，删除前必须完整备份、验证可恢复，并证明节点、L0、L1、L2 及上层引用无损；不保留旧 API、兼容表或双写。
