# ADR-0010：交付试验向导只协调证据，不执行领域动作

## Status

Accepted — 2026-08-15

ZiZu 选择由平台维护的交付试验向导，把解决方案选择、配置、安装、运行见证和报告呈现为实施工程师可完成的连续任务；向导只锁定试验基线、签发证据票据、观察既有领域事件并判断证据是否齐备，不直接提交控制命令、启用或执行策略、确认告警，也不成为通用工作流引擎。曾考虑让一个 `act` 接口代替各领域操作，或只按资源 ID、主体和时间窗猜测证据：前者会吞并控制与授权不变量，后者在重复操作时会产生歧义。证据票据因此只负责关联，原有身份权限、限值、联锁、冷却、二次确认和回读确认仍由各自深模块独立执行；验收和报告只能读取已经发生的不可变证据。

交付试验开始时锁定发布锁、解决方案包摘要和验收清单摘要，安装后再锁定安装及站点配置版本。包只能声明平台允许的固定验收种类，不能提供脚本、URL、流程图或任意代码。前端只渲染平台生成的任务卡和平台拥有的跳转意图，不显示需要人工抄录的命令 UUID、审计 UUID、响应头或自由 JSON。报告封存后不可变；若基线变化、证据归属不唯一或设备回读未确认，向导必须明确阻断而不能猜测通过。
