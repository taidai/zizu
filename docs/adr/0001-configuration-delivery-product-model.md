# ADR-0001：以版本化解决方案包实现配置式交付

## Status

Accepted — 2026-08-12

## Context

ZiZu 已有设备模板、实体、告警和规则等配置能力，但这些资产分散在数据库与界面中，无法被统一版本化、审查、安装、升级或自动验收。数据库备份会混入站点数据和环境状态，也无法安全表达客户差异。

## Decision

工业控制系统以声明式、可进入 Git 的版本化解决方案包交付。包由解决方案清单组合节点、设备、实体、告警、策略、EMS 运行工作台和验收清单，并通过强类型参数契约实例化站点差异。

安装必须支持 Schema 校验、差异预览和幂等执行；升级使用旧包、当前站点配置、新包三方差异，保留站点覆盖并显式处理冲突。数据库备份不作为解决方案包。

首版使用固定 EMS 运行工作台，不建设通用拖拽页面设计器。

## Consequences

- 配置资产获得可审查、可复用、可升级的统一边界。
- 需要新增解决方案清单 Schema、包安装器、站点覆盖和升级差异模型。
- 现有数据库内模板需要迁移或适配进入解决方案包。
- 页面自由度受平台组件白名单限制，但交付一致性和安全性提高。
