# ADR-0011：点位加工硬切换与跨节点强类型 DAG

**Status:** Accepted — 2026-08-23

ZiZu 将领域术语、代码、公开接口和数据库从“点位转换 / `point_conversion`”一次性硬切换为“点位加工 / `point_processing`”，不保留旧路由、数据库兼容视图或双写；L1 只保存不可变加工配置，运行事实只在 L0 与 L2 两级时序结构中保存。该选择牺牲了旧容器对迁移后数据库的直接兼容性，换取单一术语、单一运行路径和更低的长期维护成本；部署前必须完成数据库完整备份及隔离恢复演练，回退只能恢复备份并启动原固定摘要容器。

同一节点的点位加工可以读取本节点 L0，跨节点加工只能读取其他节点已经标准化的 L2；多级计算编译为有向无环依赖图，禁止跨节点读取品牌 L0、循环依赖和任意 Python/JavaScript。这样设备换牌只改变设备级加工模板，系统级与站级公式、告警、策略、控制和画面继续依赖稳定 L2 语义。
