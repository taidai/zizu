# ADR-0012：业务指标投影仍输出 L2，并由能力契约阻断控制

ZiZu 采用“业务指标模板 → 内部运行投影 → L2 统计实体”，不新增 L3，也不为每个指标或节点建立独立超级表。当前窗口的暂定结果保存在可恢复、可覆盖的运行投影中；只有封窗完成或审计修正的结果才写入统一 `t_l2_observations` 历史，并用独立结果修订记录保留窗口、覆盖率、计算方法、来源摘要和修订关系。该选择避免为每次采样制造历史修订，同时保持所有上层应用继续通过同一 L2 读取 seam 消费实时与历史数据。

业务指标模板是解决方案包资产，安装时解析语义来源、冻结实际来源和站点 IANA 时区，并编译为内部点位加工修订；运行异常只降低质量，不自动切换来源。即时实体和统计实体都携带不可变时间能力契约，策略与控制编译器必须递归检查完整依赖链；任何统计实体或 `control_eligible=false` 依赖都不得进入自动控制。该选择以少量专用业务模板替代面向实施人员的万能表达式编辑器，换取简单配置、确定结果、可审计修正和控制安全。
