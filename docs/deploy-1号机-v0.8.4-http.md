## 变更

- 同一次未恢复告警只通知一次；恢复后再次发生会创建新事件，并再次发送 HTTP 通知，不再被上一次事件的节流时间压住。
- 仍以事件转换标识保证 outbox 幂等，重复消费同一转换不会重复发送。
- 告警规则的实体选择新增名称/业务标识/节点搜索、节点筛选、状态规则的仅布尔实体筛选、全选/取消当前筛选结果。
- 一次最多选择 200 个实体；筛选不会清除隐藏的已选项，混合不兼容的数据类型仍由既有强类型校验拒绝。
- `notification_throttle_seconds` 暂保留为接口兼容字段，但不再跨已恢复事件压制新通知。
