## 修复内容

告警发生和恢复通知原本能够成功送达 HTTP 地址，但通知快照中的 `alarm.name` 使用了技术规则键，
导致接收方无法直接看到实施工程师配置的中文规则名称。v0.7.7 在告警事务内一次性冻结规则名称、
节点名称与完整路径、实体显示名及单位，同时保留 `alarm.rule_key` 作为稳定技术身份。数据库提交后才进入
异步投递，因此重试不会读取已经漂移的现场值或名称。

现场测试夹具同步改成持续模拟真实设备采样，而不是发送一次后等待；通过 1 号机内网 MQTT 发布，
并在接收器端口真正就绪后再开始测试。这只消除了测试自身的偶发超时，没有放宽产品的 STALE、
质量或告警语义。
