# Triage Labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工处理或决策 |
| `wontfix` | `wontfix` | 明确不进入实现 |

技能提及角色时，使用上表对应的 GitHub 标签。
