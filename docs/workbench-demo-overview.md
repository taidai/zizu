# 运行总览 Demo 复刻

本轮仅调整运行总览并补足独立负荷槽位，不修改调度或控制规则。

- 四张指标卡：光伏功率、储能 SOC、充电功率、站内负荷。
- 能流：左侧光伏/电网，右侧储能/充电桩/负荷；复用已确认 Demo 的纯 SVG 拟物图标和红金亮银样式。
- 电网仍对应 `site-power`；负荷新增 `load-power`，绝不从电网复制或推算。已有绑定不迁移、不重写。
- 在“配置首页指标”选择单位为 kW 的数值 L2 绑定负荷，沿用配置修订、幂等与权限检查。只有唯一标准 `load.active_power` / `load.activePower` 可自动匹配；多候选要求人工选择。
- 未配置显示“—”；非当前值保留最后值、质量和原因，不显示假 GOOD。充电桩及负荷方向未约定，连线静态；电网/储能沿用已确认正负方向。
- 部署须执行 `migration_065_workbench_load_slot.sql`，扩展原绑定表约束，不新增表、不删除数据。仅替换前端无法启用负荷绑定。
- Demo 内存数据、演示控制和场景切换不进入正式页面。现场真实值与截图测试夹具必须区分。
