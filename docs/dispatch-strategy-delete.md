# 调度策略删除

策略管理栏选择策略后，点击“删除策略”，确认一次即可永久删除。已启用时按钮不可用，需要先停用；后端仍独立检查启用状态和在途控制。不会自动停用或取消已下发控制来完成删除。

`DELETE /api/v1/dispatch-strategies/{strategy_id}` 需要配置写权限，成功返回 `200 {"deleted":"策略 UUID"}`。不存在返回404；启用中返回409/STRATEGY_DELETE_ENABLED；待处理、在途意图或关联控制命令仍处于accepted/validated/dispatched返回409/STRATEGY_DELETE_IN_FLIGHT。

Schema064在同一事务中硬删除所选策略、草稿、发布修订、绑定、策略事件和终态策略意图，不使用软删除或回收站。实体、原始点位、其他策略、独立控制命令及审计日志不受影响。策略存在期间，已发布修订不可更改、事件只追加的约束仍保持。

删除锁定策略行，与发布、启用和控制提交保护串行。失败回滚，不出现半删；界面仅在成功后移除策略，失败显示原因且保留编辑内容。

部署需要先备份并应用Schema064；迁移本身不删除业务记录。删除后只能从备份恢复。当前文件不代表已部署。
